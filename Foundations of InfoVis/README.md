# 🏏 IPL Data Analysis: Team & Player Insights

This project explores data from the Indian Premier League (IPL), focusing on match outcomes and deliveries. It includes team performance, toss impact, and player statistics, using powerful visualizations.

## 📊 Visualizations
- Toss winner vs. match winner comparison
- Top batsmen by runs scored
- Most dismissals by bowler
- Match wins by venue and team
- Toss decision breakdown

## 📁 Dataset
F1 Dataset

## 🛠️ Tools & Technologies
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- IPL CSV datasets
