# 🏁 Formula 1 Driver Success – A Bubble Chart Exploration

This notebook analyzes F1 driver success from 1950 to 2022 using interactive **bubble charts** to visualize performance over time.

## 📊 Visualizations
- Interactive bubble chart showing points earned by drivers per year
- Normalization using log scaling (due to large variance in points)
- Focused visual comparisons of top drivers (e.g., Schumacher vs. Hamilton)
- Dynamic filtering for post-1990 view

## 📁 Dataset
- `GrandPrix_drivers_details_1950_to_2022.csv`
- `GrandPrix_races_details_1950_to_2022.csv`

## ✨ Highlights
- Identifies top-performing drivers through visual dominance
- Uses normalization to improve readability
- Applies year-based filtering and annotation for clarity

## 🛠️ Tools & Technologies
- Python (Pandas, Plotly Express, Seaborn, Matplotlib, NumPy)
- Jupyter Notebook
- Formula 1 racing dataset (custom or public)
